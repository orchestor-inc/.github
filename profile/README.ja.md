## なぜ Orchestor が必要なのか

顧客が AI に業界や製品について質問したとき、どのブランドが紹介され、どの情報源が回答に影響しているでしょうか。マーケティングチームが知りたいのは、可視性のスコアだけではありません。回答と根拠を調べ、競合と比較し、次に何をするかを決める必要があります。

[Orchestor](https://www.orchestor.io) は、その一連の作業をワークスペースでつなぎます。

**観測する → 調べる → 優先順位を決める → 実行する**

顧客が尋ねる質問から始め、ブランドの可視性を比較し、保存された回答と引用元を確認します。その結果をコンテンツの改善計画に活かし、次の作業を追跡します。Web アプリで使うほか、CLI・スキル・MCP を通じて普段のエージェントからも進められます。

## Orchestor でできること

| 機能 | できること |
| :--- | :--- |
| **ブランドの可視性** | AI 回答に自社ブランドがどう登場するかを観測し、競合と比較します。 |
| **質問のモニタリング** | 顧客にとって重要な質問を追跡し、回答の変化を確認します。 |
| **回答・引用元の確認** | 保存された回答、引用されたページ、結果の根拠となる情報源を調べます。 |
| **ブランド評価の把握** | AI がブランドをどう説明しているか、その評価と根拠を確認します。 |
| **調査・レポート** | 競合やコンテンツの不足を調査し、出典とともに結果をまとめます。 |
| **改善ワークフロー** | 調査結果を改善案と追跡可能なタスクにし、対象のワークスペースで管理します。 |

ブランド・質問・回答・情報源・レポートを、次のアクションを決めるための文脈として使えます。判断するときに、その根拠までたどれます。

## エージェントで始める

スキルを追加し、必要なものを選びます。

```sh
npx skills@latest add orchestor-inc/skills
```

まとめて導入する場合は、プラグインを使えます。

```sh
npx plugins add orchestor-inc/orchestor-plugin
```

同じスキルを重複して入れないよう、導入方法はどちらかを選びます。[CLI セットアップガイド](https://orchestor.io/docs/cli) に沿ってワークスペースへ接続してください。CLI と MCP の認証はそれぞれ必要です。

接続後は、エージェントにこう依頼できます。

> 過去 30 日間の自社ブランドの可視性を、この競合と比較してください。引用元を示し、次に取り組む 3 つのアクションを提案してください。
